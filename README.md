# Maksim Timoshin

**AI Engineer · Agent Systems & Harness Engineering**  
**Research focus: Living Harness and controlled agent evolution.**

I design and build agent systems and the infrastructure that makes them useful in real work. My focus is on persistent context, execution control, and how evidence from completed tasks can guide verified improvements to an agent's harness.

## Current work

### AI Alyx

An agent workspace under active development, with Living Harness as its central research direction.

The problem I am working on: how an agent can carry useful experience between tasks, while changes to its operating environment remain observable, testable, and reversible.

The current implementation is private. A public overview will describe the problem, design principles, and selected engineering decisions.

### Inference systems laboratory

A separate project for investigating model runtimes, hardware constraints, and workload-dependent performance, with an intended open-source release.

The goal is to make configuration decisions easier to reproduce and explain through measurement. Local inference is one part of my broader work with cloud and local models and different model architectures.

## Research questions

- **Agent infrastructure:** how should context, tools, state, and execution policies work together across long-running tasks?
- **Living Harness:** which lessons from execution should persist, and how can proposed changes be evaluated before adoption?
- **Inference systems:** how do models, runtimes, hardware, and workloads affect practical performance?
